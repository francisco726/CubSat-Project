# CubeSat Attitude Control Project
This is a personal aerospace engineering project focused on the design and simulation of a CubeSat platform.

The project currently includes:
- mechanical CAD design in SolidWorks
- deployable solar panels
- subsystem layout
- mass and inertia considerations

Future work will include:
- attitude dynamics simulation
- reaction wheel modeling
- PID/LQR attitude control
- CAD-to-Python integration
